# Playwright capability and exclusion ledger

This ledger maps named behaviour to the executable test that checks it. A mocked integration journey proves the WebApp contract at its browser boundary; it does not prove that a downstream service persisted a change. The live create-case readback uses the configured target environment without route mocks. EXUI-5639 supplies current discovery counts; this ledger makes no percentage claim.

## Default integration exclusions

The owner is the repository [CODEOWNERS](../.github/CODEOWNERS) team, `@hmcts/exui-team`. Each tag is in [integration/tag-filter.json](integration/tag-filter.json) with its Jira issue and a **31 December 2026** recheck date. The reasons below come from the test names and source comments; they are not a fresh Jira-status assessment. The date is an owner review trigger, not a claim that the product fix will be ready. The integration config still omits these tests by default; use `INTEGRATION_PW_EXCLUDED_TAGS_OVERRIDE=@none` for an explicit review run.

| Tag / issue                      | Excluded behaviour and source-documented reason                                           | Recheck criterion                                                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `@blocked-exui-4272` / EXUI-4272 | Create-case bootstrap error tests expect an error UI that the app has not implemented.    | Re-enable when each mocked 4xx/5xx bootstrap response renders the expected error and the focused negative spec passes. |
| `@blocked-exui-4276` / EXUI-4276 | Malformed task data is currently rendered instead of rejected safely.                     | Re-enable when the malformed task response produces the intended safe error state.                                     |
| `@blocked-exui-4317` / EXUI-4317 | Changing gender hides Maiden Name but the submit payload still includes the hidden value. | Re-enable when the submitted Person1 payload omits MaidenName and the positive spec passes.                            |
| `@blocked-exui-4318` / EXUI-4318 | Task Go To reaches case details but omits the task error message after a failed endpoint. | Re-enable when both 400 and 500 mocked responses show the expected error alongside safe navigation.                    |
| `@blocked-exui-5589` / EXUI-5589 | Role removal and reallocation readback does not match the expected role state.            | Re-enable both role mutation specs when the action payload, return route and refreshed role rows all pass.             |
| `@blocked-exui-5591` / EXUI-5591 | Hearing unlink skips the required review screen.                                          | Re-enable when unlink shows review before confirmation and refreshed groups match the intended change.                 |
| `@blocked-exui-1004` / EXUI-1004 | A dependent answer is lost at check-your-answers after its source page is skipped.        | Re-enable when the value survives the conditional journey and submitted payload.                                       |
| `@blocked-exui-5590` / EXUI-5590 | MyTasks omits the selected location after a summer booking range.                         | Re-enable when the selected work location appears after refresh and the UTC range remains correct.                     |

On the recheck date, the owning team reviews issue status and runs the focused spec with exclusions overridden. Remove the exclusion only when the business assertion passes; a green discovery count alone is insufficient.
